# Общее описание функций

## int sum(int a, int b)

Возвращает сумму двух чисел.

### Параметры функции
    
- a, b - целые числа.
    
### Возвращаемое значение

- Результат - сумма чисел **a** и **b**

>[!WARNING] 
> Ограничения:
>
> - (a + b) <= 2 147 483 647
> - (a + b) >= -2 147 483 648
    
### Пример вызова функции

```cpp
int result1 = sum(5, 8);  // result1 = 13
int result2 = sum(-4, 2); // result2 = -2
```

## int sub(int a, int b)

Возвращает результат разности двух чисел.

### Параметры функции
    
- a, b - целые числа
- a - уменьшаемое
- b - вычитаемое
    
### Возвращаемое значение

- Результат - разность чисел **a** и **b**

>[!WARNING] 
> Ограничения:
>
> - (a - b) <= 2 147 483 647
> - (a - b) >= -2 147 483 648
    
### Пример вызова функции

```cpp
int result1 = sub(8, 5);  // result1 = 3
int result2 = sub(-4, 2); // result2 = -6
```

## int di(int a, int b)

Возвращает результат целочисленного деления двух чисел.

### Параметры функции
    
- a, b - целые числа.
- a - делимое
- b - делитель
    
### Возвращаемое значение

- Результат - частное чисел **a** и **b**; Дробная часть отбрасывается

>[!WARNING] 
> Ограничения:
>
> - b != 0
> - (a / b) <= 2 147 483 647
> - (a / b) >= -2 147 483 648
    
### Пример вызова функции

```cpp
int result1 = di(37, 5);  // result1 = 7
int result2 = di(-4, 2);  // result2 = -2
```

## int mod(int a, int b)

Возвращает остаток от деления двух чисел.

### Параметры функции
    
- a, b - целые числа.
- a - делимое
- b - делитель
    
### Возвращаемое значение

- Результат - остаток от деления числа **a** на **b**

>[!WARNING] 
> Ограничения:
>
> - b != 0
> - (a % b) <= 2 147 483 647
> - (a % b) >= -2 147 483 648
    
### Пример вызова функции

```cpp
int result1 = mod(37, 5);  // result1 = 2
int result2 = mod(-5, 2);  // result2 = -1
```
