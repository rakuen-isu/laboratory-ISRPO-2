# Общее описание решения

## Калькулятор

### Общее

- Калькулятор на языке программирования C++ с базовыми операциями `+`, `-`, `*`, `/`, `%`.
- Вызов калькулятора производится через терминал компилятора C++ (см. [Сборка и запуск](#сборка-и-запуск)).
- Для написания калькулятора общий код был поделён на 3 файла `calculator.cpp`, `functions.cpp`, `funcs.h`.

### [calculator.cpp](../calculator.cpp)

- Исполняемый код
- Программа получает на вход два числа и оператор:

```
number1 operator number2
```

- где `number1`, `number2` - целые числа типа `int`, а `operator` - оператор из списка: `+`, `-`, `*`, `/`, `%`.
- Выводит результат выражения.

### [functions.cpp](../functions.cpp)

- Код, где определяются все функции, связанные с арифметическими действиями, такие как сумма (`sum`), разность (`sub`) и т.д.

> [!IMPORTANT]
> - [Подробнее о функциях](functions.md)
> - [Объявление функций](../funcs.h)

### [funcs.h](../funcs.h)

- Заголовочный файл с объявлениями функций из [functions.cpp](../functions.cpp)

### Сборка и запуск

> [!NOTE]
> Команды стоит выполнять в корне репозитория, где лежит `calculator.cpp` и `functions.cpp`.
>
> Требуется компилятор `g++`. (MinGW/MSYS2 на Windows)

#### На Linux

``` 
g++ calculator.cpp functions.cpp -o calculator
./calculator
```

#### На Windows (в MSYS2)

```
g++ calculator.cpp functions.cpp -o calculator.exe
./calculator.exe
```
